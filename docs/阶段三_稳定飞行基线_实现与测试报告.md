# 阶段三稳定飞行基线：实现与测试报告

> 日期：2026-10-30｜范围：4 个任务级专家智能体（strike/patrol/defense/ew）的本机稳定飞行；不含 JSRL、多机、长训练。
>
> 结论：**`control_mode=assisted` 下，4 任务 × 3 固定 seed × safe/512 步模型共 24 次隔离飞行全部完成 240 步，0 次 `own_crash`；ActionV1 7 维契约不变；122 项 pytest 全绿。**

---

## 1. 根因诊断（raw_fcs）

### 1.1 现象

上一版 `stage3_expert_validation` 中，4 个任务级智能体评估在 36~39 步因 `own_crash` 终止。进一步固定油门 0.0/0.2/0.5/0.55/0.8、零舵面仍分别在 50/49/46/45/41 步坠地，说明不是“策略近零油门”单一原因。

最小复现（strike，seed=42，固定油门 0.55、零舵面、240 步、敌方不发射）：

```text
raw_fcs: 45 步 own_crash，最终高度 -2.1 m，最大 |theta| 0.689 rad
```

### 1.2 根因

`BVRCombatEnv` 原先本机：

```python
self.own.reset(..., autopilot=False)          # 本机 AP 关闭
self.own.step_manual(throttle, roll, pitch, yaw, n_frames)  # 直接驱动 F-104 舵面
```

而敌机使用 `autopilot=True` + `step_ap`。本机人工通道没有配平/俯仰保持/高度保持：

- 零升降舵并不能保持平飞，F-104 在随机初始高度/速度下会持续低头；
- 油门只改变能量，不纠正姿态；固定油门越大，低头加速越快，坠地反而更早；
- 因此 `own_crash` 是**控制通道/内环缺失**问题，不是单纯 DRL 策略未训练。

对照：JSBSim AP 在固定高度/速度设定下可稳定保持（实测初始约 5266 m，稳定在约 5164 m，静差约 100 m，240 步不坠地）。

## 2. 实现：`control_mode=assisted`

### 2.1 改动点

| 文件 | 改动 |
|---|---|
| `多任务智能体/common/control_mode.py`（新增） | `raw_fcs/assisted` 枚举、ActionV1→AP 设定值唯一映射、参数校验 |
| `common/bvr_combat_env.py` | `DEFAULT_CONFIG` 增加 `control_mode`（默认 `raw_fcs`）；本机 `reset` 在 assisted 下接通 AP；`step` 在 assisted 下调用 `step_ap`，raw_fcs 仍调用 `step_manual`；reset 记录 `_assisted_alt_ref_m` |
| `agents/task_agents/mission_env.py` | `MissionMixin` 默认 `control_mode=assisted`，`FlatTaskMissionEnv`/`TaskMissionEnv` 共用 |
| `agents/policy_interface.py` | `action_spec` 增加 `control_mode`、`control_modes`、`assisted_mapping`、连续维语义 |
| `agents/action_adapter.py` | `to_ap_command`/`command_v1` 改用同一 assisted 映射；新增 `to_assisted_setpoints` |
| `agents/task_agents/base_task_agent.py` | 任务级智能体默认 assisted；`*.spec.json` 写入 control_mode |

`JSBSimGymBridge` 未改接口，直接复用既有 `step_ap`（AP 主开关、高度保持、速度保持、滚转保持）。

### 2.2 assisted 映射（ActionV1 契约不变）

ActionV1 仍为 `(7,) float32`：

| 索引 | 字段 | 范围 | assisted 语义 |
|---:|---|---|---|
| 0 | throttle | [0,1] | `v_cmd = 180 + 100·throttle` m/s（0.55→235） |
| 1 | roll | [-1,1] | `roll_cmd = 0.90·roll` rad |
| 2 | pitch | [-1,1] | `alt_cmd = clip(alt_ref + 500·pitch, 3000, 8000)` m |
| 3 | yaw | [-1,1] | 忽略（AP 滚转协调转弯） |
| 4 | fire | {0,1} | 边沿触发，语义不变 |
| 5 | switch | {0,1} | 边沿触发，语义不变 |
| 6 | ecm | {0,1} | 边沿触发，语义不变 |

- `alt_ref` 在 `reset` 时固定为本机初始高度；`pitch=0` 即保持初始高度，避免“设定值跟随当前高度”导致 AP 无静差修正、缓慢下沉；
- 训练 `FlatTaskMissionEnv`、部署 `TaskMissionEnv`、行为树 `to_env_action` 全部经同一环境/映射，不存在训练/部署两套语义；
- `raw_fcs` 仍可用：`BVRCombatEnv` 默认值保持 `raw_fcs`，现有 BVR 单测与历史行为不受影响；任务级 `MissionMixin` 默认 assisted，显式传 `control_mode="raw_fcs"` 可对照。

### 2.3 `action_spec` 示例字段

```json
{
  "version": "action_v1",
  "dim": 7,
  "control_mode": "assisted",
  "control_modes": ["raw_fcs", "assisted"],
  "assisted_mapping": {
    "throttle": "v_cmd_mps = 180 + 100*throttle",
    "roll": "roll_cmd_rad = 0.90*roll",
    "pitch": "alt_cmd_m = clip(alt_ref_m + 500*pitch, 3000, 8000)",
    "yaw": "ignored (AP coordinated turn)"
  }
}
```

## 5. 已知限制与风险

1. **assisted 是稳定飞行基线，不是战术自动驾驶**：AP 高度保持有约 100 m 静差；pitch 仅 ±500 m 偏移；大机动/能量管理未调优。
2. **模型仅 512 步**：速度最低约 114 m/s，模型策略尚未学会能量/战术；本轮只证明不坠机与接口一致。
3. **正常战斗会被命中**：安全基线不规避、不发射；54 步 `own_hit` 仅记录，不代表任务性能。
4. **raw_fcs 仍不稳定**：保留为兼容/对照，不应作为任务级默认；如后续需要纯舵面训练，需另做配平/增稳内环。
5. **未做**：完整 JSRL、多机、HVA、混合动作策略、LSTM、80~120 km/600 步最终场景。
6. **未 push**：两个 commit 仅本地，工作区最终应保持干净。
