# 阶段三 引导行为树搭建工作计划

> 目标：完成“人类招式库 + 引导行为树 + GuideProvider + 80–120 km 验证”，为后续 JSRL 训练提供稳定教师。
> 本轮不启动 1e6/1e7 长训练；JSRL 训练循环只预留接口，不在本计划内实现。

## 1. 范围与验收

### 范围

- 统一接口：`ObsV1(28) + ActionMaskV1(7) + ActionV1(7) + control_mode`；
- 新增 `GuideStep` 与 `BTGuideProvider`；
- 控制模式：高层引导 + `assisted`，连续飞行仍由 DRL/现有控制器输出；
- 人类招式库：核心 10–15 个 `ManeuverSpec`；
- 行为树：手写参考树 + LLM 生成树；
- 场景：80–120 km / 600 步为主，30–80 km / 240 步回归；
- LLM：mock 离线回归 + DeepSeek 在线最终树。

### 验收线

| 项目 | 目标 |
|---|---|
| 静态校验 | 0 错误 |
| OODA | 8/8，执行覆盖 100% |
| 80–120 km / 600 步 | 存活 ≥80%，命中 ≥50% |
| 30–80 km / 240 步回归 | 不低于现有 90%/75% |
| 误发射 | 0% |
| 安全违规 | 0 |
| node_trace | 20/20 |
| 接口单测 | GuideStep/Provider/Adapter/Manuever 全绿 |
| 全量回归 | 三套测试全绿 |

## 4. 数据工作流

1. **ACMI**：用 `tools/fetch_dcs_acmi.py` 增量下载；按文件名/日期/大小筛选；已存在自动跳过；`manifest.csv` 记录 SHA256。
2. **MIT**：签署 Data Sharing Agreement 后下载 sample maneuvers；不公开转发。
3. **F-16 手册**：用于战术定义，不直接复制参数到 F-104。
4. **UAVDB/CAFUC**：用于基础机动几何/响应，不直接当作 BVR 战术数据。
5. **招式表**：每个招式必须有 `source_ref` 和 `status`；没有来源/退出条件的招式不进入正式库。

## 5. 风险与控制

| 风险 | 控制 |
|---|---|
| 控制模式混用 | P0 明确 assisted；禁止 raw_fcs 直喂 |
| 80–120 km 教师质量不足 | 先手写参考树，再让 LLM 生成；固定 20 seeds |
| 招式库膨胀 | 只用 `execute_maneuver` 单节点 + 注册表 |
| LLM 自评偏差 | 固定外部 harness；20 seeds |
| 数据许可 | 每个来源记录 license/使用边界；不重新分发 |
| 训练范围膨胀 | 本轮不跑 JSRL 长训练；只到 GuideProvider + 验证 |
