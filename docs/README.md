## 证据目录约定

- `assets/2.x_*`：阶段二各步骤证据；
- `assets/3.x_*`：阶段三教师树、候选搜索与训练证据；
- 树文件的场景路由与指标摘要以 `引导策略行为树/tree_manifest.json` 为准；
- 运行产物 `outputs/`、`models/`、`results/` 不入库，可由命令重新生成。
