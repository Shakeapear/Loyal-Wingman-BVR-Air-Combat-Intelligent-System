## 1. 范围

| 能力 | 实现 | 产物 |
|------|------|------|
| 2D 战术显示 | Matplotlib（TkAgg）俯视态势：双方轨迹、导弹、攻击区扇形（`radar_az_limit_deg`）、RWR/MAWS、态势面板 | 实时窗口 / 离屏帧 |
| 逐帧录制 | `EpisodeRecorder`，CSV（`csv_v1`，含 `steps`、位置/姿态/速度/油量/事件等） | `results/*.csv` |
| 回放渲染 | `visualization.replay` / `offscreen.render_episode` | GIF（默认）；MP4（已安装 `imageio-ffmpeg` 0.7.0，自带 FFmpeg 7.1） |
| 3D 复盘 | 自研 ACMI 2.2 导出（`acmi.py`、`csv2acmi.py`） | `results/*.acmi`（TacView 打开） |
| Gym 渲染接入 | `BVRCombatEnv.render(render_mode="human"/"rgb_array")`，惰性导入工具，`render_mode=None` 零开销 | — |

工具与智能体库只通过 `get_viz_frame()` 帧字典（ENU+SI）单向解耦；除 `demo.py` 外，录制/渲染/ACMI 模块不依赖智能体库，可离线处理任意 CSV。

## 3. 使用命令（DC 环境）

```powershell
# 在 可视化工具/ 目录下
# 1) 离线演示：CSV + GIF + ACMI（无实时窗口）
python -m visualization.demo --seed 8 --no-live --acmi

# 2) 仅录制 CSV + ACMI（跳过 GIF，最快）
python -m visualization.demo --seed 8 --no-live --no-gif --acmi

# 3) 回放任一 CSV → GIF
python -m visualization.replay results/demo_ep_seed8.csv --fps 10

# 3b) 回放任一 CSV → MP4（imageio-ffmpeg 已安装）
python -m visualization.replay results/demo_ep_seed8.csv --out results/demo_ep_seed8.mp4 --fps 10

# 4) 任意 CSV → ACMI（TacView 3D）
python -m visualization.csv2acmi results/demo_ep_seed8.csv
```

```powershell
# 行为树仿真 + 录制（在 引导策略行为树/ 目录下）
python -X utf8 run_tree_sim.py --seed 9
```

TacView：安装后双击 `.acmi` 即可；多份对比可多开实例。界面元素与操作见 `TacView观看指引.md`。

## 4. 依赖与限制

- 依赖：`matplotlib`（TkAgg，实时窗口需桌面环境，GIF 用 PillowWriter）、`imageio-ffmpeg 0.7.0`（MP4，自带 FFmpeg 7.1）；均已可用。
- 系统 `ffmpeg` 已在机器级 PATH（`D:\Program Files\ffmpeg-master-latest-win64-lgpl-shared\bin`），命令行可直接调用；`ffmpeg-9.0.2.tar.xz` 仅为源码包，未编译、未加入 PATH。
- **FlightGear 方案 B 未做**（按计划后置）；当前 3D 复盘走 TacView ACMI 2.2。
- `results/`、`outputs/` 为运行产物目录，不入库；演示策略为脚本策略，非训练产物。
- 实时窗口与离屏渲染共用同一绘图内核，但窗口需要可交互桌面；服务器/无显示环境请用 `--no-live`。
