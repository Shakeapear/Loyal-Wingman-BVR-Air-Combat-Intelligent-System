## 3. 使用命令（DC 环境）

```powershell
# 在 可视化工具/ 目录下
# 1) 离线演示：CSV + GIF + ACMI（无实时窗口）
python -m visualization.demo --seed 8 --no-live --acmi

# 2) 仅录制 CSV + ACMI（跳过 GIF，最快）
python -m visualization.demo --seed 8 --no-live --no-gif --acmi

# 3) 回放任一 CSV → GIF；--out results/x.mp4 输出 MP4（需 imageio-ffmpeg）
python -m visualization.replay results/demo_ep_seed8.csv --fps 10

# 4) 任意 CSV → ACMI（TacView 3D）
python -m visualization.csv2acmi results/demo_ep_seed8.csv
```

```powershell
# 行为树仿真 + 录制（在 引导策略行为树/ 目录下）
python -X utf8 run_tree_sim.py --seed 9
```

TacView：安装后双击 `.acmi` 即可；多份对比可多开实例。界面元素与操作见 `TacView观看指引.md`。

## 4. 依赖与限制

- 依赖：`matplotlib`（TkAgg，实时窗口需桌面环境）、`imageio`（GIF）；已可用。
- **MP4 需 `imageio-ffmpeg`**：当前环境未安装（`import imageio_ffmpeg` 失败），GIF 与 CSV/ACMI 不受影响。
- **FlightGear 方案 B 未做**（按计划后置）；当前 3D 复盘走 TacView ACMI 2.2。
- `results/`、`outputs/` 为运行产物目录，不入库；演示策略为脚本策略，非训练产物。
- 实时窗口与离屏渲染共用同一绘图内核，但窗口需要可交互桌面；服务器/无显示环境请用 `--no-live`。
