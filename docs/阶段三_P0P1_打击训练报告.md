## 5. CPU/GPU 基准与选型

### 5.1 20k pilot 吞吐（本地 CPU）

| 策略 | 并行 | 20k wall | steps/s | 1e7 估算 |
|------|------|--:|--:|--:|
| P1 hybrid | DummyVecEnv×8 | 172.65 s | 115.8 | 24.0 h |
| P0 mlp | DummyVecEnv×8 | 153.56 s | 130.2 | 21.3 h |
| P1 hybrid | SubprocVecEnv×8 | 118.00 s | 169.5 | 16.4 h |
| P0 mlp | SubprocVecEnv×8 | 99.72 s | 200.6 | 13.9 h |

本地：i7-14700HX（20C/28T）、31.7 GB。SubprocVecEnv 相对 Dummy 提升约 1.46–1.54×；长训练必须用 Subproc。

### 5.2 为什么推荐 CPU

- 单环境 `env.step` 1.057 ms（946 steps/s）；混合网络 batch=256 前向 44.3 万样本/s，前向+采样+反传 13.3 万样本/s；
- 端到端瓶颈是 JSBSim/Python 环境与进程通信，不是矩阵运算；
- GPU 实例通常 CPU 核数更少、单价更高，预计加速 <1.5×；本机无 GPU，未租 GPU 实例做实测（遵守“未确认不租用”）。

详细平台对比与 3 个方案见 `docs/阶段三_P0P1_服务器配置建议.md`。

## 6. 20k pilot 评估结果

固定 seeds 1–20，deterministic，600 步：

| 指标 | P0 mlp | P1 hybrid |
|------|--:|--:|
| 命中率 | 0%（0/20） | 5%（1/20） |
| 存活率 | 80%（16/20） | 25%（5/20） |
| 误发射率 | 0%（0 发射） | 0%（6 发射，0 非法） |
| 安全违规 | 0 | 0 |
| 平均步数 | 515.5 | 348.5 |
| 平均回报 | 367.46 | 136.51 |
| 终止分布 | timeout 16 / own_hit 4 | own_hit 15 / timeout 4 / enemy_hit 1 |

图：`docs/assets/stage3_p0p1_pilot/pilot_eval_compare.png`、`pilot_learning_curves.png`。

### 6.1 失败/现象分析（20k，不代表最终）

- **P0 不发射**：20 局 0 次发射，主要靠超时存活；命中 0% 是“不会打”而非“打不中”。这不是有效的 <30% 基线结论，长训练需观察是否学会进入攻击区并发射。
- **P1 会发射但生存差**：6 次发射、1 次命中；15 局 `own_hit`，大量 episode 在 146–190 步结束，说明早期策略过于前压/规避不足。掩码保证 0 非法发射、0 安全违规。
- **共同点**：0 安全违规、0 误发射；说明动作合法性和掩码链路在真实环境中工作。
- 20k 步远低于 1e7，以上仅用于验证训练链路与吞吐，不作为 P0/P1 性能验收。

  --timesteps 20000 --n-envs 8 --vec-env subproc `
  --n-steps 256 --batch-size 64 --n-epochs 10 --seed 0 `
  --scene bvr80-120 --out-dir models/pilot_20k_subproc/hybrid `
  --eval-freq-episodes 0 --checkpoint-episodes 0

# 固定测试集

  --model models/pilot_20k_subproc/hybrid/hybrid_ppo_final.zip `

  --out-dir models/pilot_20k_subproc/hybrid/eval_fixed
