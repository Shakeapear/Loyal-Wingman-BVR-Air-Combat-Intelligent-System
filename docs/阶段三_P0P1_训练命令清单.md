# 阶段三 P0/P1 打击训练命令清单

> 适用：Linux Ubuntu 22.04/24.04，16 vCPU/32 GB CPU 实例（推荐），Python 3.12。
> 前提：用户已确认平台/区域/预算/时长；当前**尚未租用实例**。
> 代码：本地 main 领先远端；服务器需使用用户提供的 Git bundle/zip 或已包含对应 commit 的远端，不假设 GitHub 已有最新 commit。

## 0. 本地打包与传输（不上传密钥）

```powershell
# 在仓库根（Windows）
git status --short
git log -1 --oneline
git bundle create ..\bvr_p0p1.bundle HEAD
# 或压缩工作区（必须包含 JSBSim/，否则服务器初始化 FDM 会失败）
Compress-Archive -Path "多任务智能体","JSBSim","引导策略行为树","可视化工具","docs" `
  -DestinationPath "..\bvr_p0p1.zip" -Force
```

> 易错点：早期命令只打包了 `多任务智能体/`，服务器上会因缺少
> `JSBSim/aircraft/f104/f104.xml`、`reset_cruise.xml` 而在
> `FGFDMExec/load_model` 阶段失败。推荐优先使用 `git bundle`（包含全部已跟踪文件）。
> 上述 zip 仅覆盖专家训练；若要复跑 LLM 树静态校验，还需包含
> `开源项目库/03_行为树与LLM/BTGenBot/Python重写_bt_validator/`。

传输到服务器（示例，按实际地址/端口）：

```bash
scp bvr_p0p1.bundle user@SERVER:/home/user/
```

## 6. 1e6 pilot（先各跑 1e6，确认吞吐/曲线）

> 默认 `--compute-envelope` 与旧基线一致；如需测吞吐上限可加
> `--no-compute-envelope`。奖励归一化默认关闭，AB 对比时加
> `--normalize-reward`（会另存 `vecnormalize.pkl`，续训需一起保留）。
> P0 无掩码时误发射高；可加 `--mask-actions` 跑“环境侧掩码”对照，默认仍是纯 PPO。
> 模型加载会校验 task/policy/观测维度/scene；策略与 checkpoint 不匹配会直接失败。

```bash
cd 多任务智能体

# P0 纯 PPO（28 维，无 MaskedObsWrapper）
tmux new -s p0_1m
python -X utf8 -m agents.ppo_agent --task strike --policy mlp \
  --timesteps 1000000 --n-envs 8 --vec-env subproc \
  --n-steps 256 --batch-size 64 --n-epochs 10 --learning-rate 3e-4 \
  --seed 0 --scene bvr80-120 --out-dir models/p0_strike_1m \
  --tensorboard --tb-log tensorboard/p0_1m \
  --eval-freq-episodes 500 --checkpoint-episodes 1000 --eval-seeds 1-20
# Ctrl-b d 脱离；tmux attach -t p0_1m 查看

# P1 混合动作（35 维，含掩码）
tmux new -s p1_1m
python -X utf8 -m agents.ppo_agent --task strike --policy hybrid \
  --timesteps 1000000 --n-envs 8 --vec-env subproc \
  --n-steps 256 --batch-size 64 --n-epochs 10 --learning-rate 3e-4 \
  --seed 0 --scene bvr80-120 --out-dir models/p1_strike_1m \
  --tensorboard --tb-log tensorboard/p1_1m \
  --eval-freq-episodes 500 --checkpoint-episodes 1000 --eval-seeds 1-20
```

## 7. 1e7 长训练（用户确认预算后）

```bash
cd 多任务智能体

# P0
tmux new -s p0_10m
python -X utf8 -m agents.ppo_agent --task strike --policy mlp \
  --timesteps 10000000 --n-envs 8 --vec-env subproc \

  --seed 0 --scene bvr80-120 --out-dir models/p0_strike_10m \
  --tensorboard --tb-log tensorboard/p0_10m \
  --eval-freq-episodes 500 --checkpoint-episodes 1000 --eval-seeds 1-20 \
  --final-eval
# Ctrl-b d

# P1
tmux new -s p1_10m
python -X utf8 -m agents.ppo_agent --task strike --policy hybrid \
  --timesteps 10000000 --n-envs 8 --vec-env subproc \
  --n-steps 256 --batch-size 64 --n-epochs 10 --learning-rate 3e-4 \
  --seed 0 --scene bvr80-120 --out-dir models/p1_strike_10m \
  --tensorboard --tb-log tensorboard/p1_10m \
  --eval-freq-episodes 500 --checkpoint-episodes 1000 --eval-seeds 1-20 \

```

断线恢复：

```bash
tmux attach -t p0_10m
# 若进程中断，从最新 checkpoint 继续（文件名含 step，避免续训覆盖）：
LATEST=$(ls -t models/p0_strike_10m/checkpoints/*.zip 2>/dev/null | head -1)
if [ -z "$LATEST" ]; then
  echo "未找到 checkpoint，停止续训（避免误覆盖 training_log.csv）" >&2
  exit 1
fi
python -X utf8 -m agents.ppo_agent --task strike --policy mlp \
  --timesteps 9000000 --n-envs 8 --vec-env subproc \
  --seed 0 --scene bvr80-120 --out-dir models/p0_strike_10m \
  --resume "$LATEST" \
  --eval-freq-episodes 500 --checkpoint-episodes 1000 --final-eval
```

> `checkpoints/*.zip` 同时匹配 `ckpt_ep*_step*.zip` 与
> `hybrid_strike_*_steps.zip` / `mlp_strike_*_steps.zip`。
> 如果输出目录已有训练产物，`ppo_agent` 默认拒绝从头重跑；确需重跑请加
> `--overwrite` 或换 `--out-dir`，避免覆盖旧日志。

> P1 resume 同理，把 `--policy hybrid` 改掉。`--timesteps` 是**本次追加步数**；
> 续训会保留 `num_timesteps` 累加，`training_log.csv` 追加而不是截断。
> `--checkpoint-freq`（按环境步保存）在 hybrid/mlp 两条路径均启用，文件名由
> SB3 生成 `hybrid_strike_<steps>_steps.zip` / `mlp_strike_<steps>_steps.zip`；
> 两者均可用 `--checkpoint-episodes`（按 episode 保存，文件名含 step）。

## 10. 费用/时长控制

- 先跑 1e6 pilot；若 1e6 后 `training_log.csv` 无奖励上升/无发射，暂停分析，不直接烧 1e7。
- 设云监控/余额告警；超过用户预算或 48 h 暂停并报告。
- Spot 实例中断后从最近 checkpoint 恢复；不要重复从头训练。
- 训练结束立即 `sudo shutdown -h now` 或释放实例，避免闲置计费。

## 11. 红线

- 不改 `common/bvr_combat_env.py` 物理/奖励/终止；
- 不改 `agents/hybrid_policy.py` 网络数学/掩码语义；
- 不跑 JSRL/LSTM/多机/其他任务；
- 不 push；不提交模型/大日志/密钥；
- 不在未确认时租用 GPU 或启动 1e7。
