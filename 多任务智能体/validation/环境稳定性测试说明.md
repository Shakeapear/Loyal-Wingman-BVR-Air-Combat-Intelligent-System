## 1. 运行前提

| 前提 | 说明 |
|------|------|
| 环境 | conda `DC`（Python 3.12 + jsbsim 1.2.4，已配置），无需 API/网络 |

## 3. 命令与参数一览

| 参数 | 默认 | 说明 |
|------|------|------|
| `--episodes N` | 1000 | episode 总数；`<1000` 视为冒烟（不写续跑进度） |
| `--policy level` | level | `level`=近水平巡航动作（长局，自然超时/被命中终止）；`random`=随机动作（短局，坠毁终止） |
| `--envelope` | 关 | reset 时解算攻击区（+约 1.2 s/次，更接近真实训练工况） |
| `--base-seed` | 10000 | episode i 的 seed = base+i，同参数结果可复现 |
| `--no-resume` | 关 | 忽略进度文件从头跑 |

## 4. 断点续跑

- 中断（Ctrl+C、关机）后**重新执行同一条命令**即可：脚本读取
  `results/stability_progress.json` 的完成数与统计，从下一 episode 继续，耗时累计；
- 想从头重跑：加 `--no-resume`；
- 进度文件与会话绑定策略/参数；若更换 `--policy`/`--envelope`，请先删除进度文件或加 `--no-resume`。

## 5. 判定标准与预期结果

**通过标准（全部满足）：**

1. 未捕获异常 = 0 次（报告「未捕获异常：0 次」）；
2. 观测非有限值 = 0 次、奖励非有限值 = 0 次；
3. 1000 个 episode 全部完成（无论其终止原因）。

**报告解读（示例结构）：**

```
episode 总数：1000（policy=level，compute_envelope=False，base_seed=10000）
累计耗时：0:08:12   总决策步：158000   平均步/秒：321.1
未捕获异常：0 次
观测非有限值：0 次；奖励非有限值：0 次
episode 终止原因分布：enemy_hit×412, own_hit×388, timeout×142, escape×58
结论：通过（无崩溃，观测/奖励始终有效）
```

- **终止原因分布不是失败条件**：巡航策略不做规避，被命中/超时终止均属正常
  episode 结束；统计用于记录环境各终止路径都被覆盖；
- 异常 episode 会打印完整 traceback 并重建环境继续跑完（最终判定失败），
  便于定位；
- 冒烟实测参考（2026-09-17）：level 策略 5 episode ≈ 2 s / 281 步；
  random 策略 20 episode ≈ 25 s / 689 步。

## 6. 常见问题

| 现象 | 处理 |
|------|------|
| 中文输出乱码 | 命令加 `-X utf8`（或 `$env:PYTHONIOENCODING="utf-8"`） |
| 步/秒明显偏低 | 检查是否有其他 Python/训练进程争抢 CPU；确认在 `多任务智能体/` 目录运行 |
| 重跑时提示「续跑」但想重来 | 加 `--no-resume`，或删除 `results/stability_progress.json` |
| 想用更接近真实训练的工况 | 加 `--envelope`（耗时增加，判定标准不变） |
