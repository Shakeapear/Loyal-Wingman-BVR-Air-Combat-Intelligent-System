# 飞行数据集资料库

本目录收集与本大创项目（忠诚僚机超视距空战、JSBSim 仿真、DRL/行为树决策）直接相关的**公开飞机飞行动作数据集与仿真环境**，作为项目数据基础和组员学习范例。

**收集时间：** 2026-08-16（联网检索，来源均为公开可获取资源）
**整理人：** 李欣洋（供全组使用）

## 目录结构

```
飞行数据集资料库\
├── 01_单机飞行动作数据\          ← 单机机动/飞行动作数据（真实飞行与仿真）
│   ├── UAVDB_真实机动飞行数据\   ← 已下载：真实试飞机动数据（.mat，约 29MB）
│   ├── CAFUC_民航训练机动数据\   ← 需注册下载：民航教练机训练机动（813KB）
│   └── aircraft_maneuver_classification_机动分类\ ← 需自行克隆：机动分类数据集
├── 02_多机空战与协同\            ← 多机对抗/协同环境（含场景与行为树参考）
│   ├── CloseAirCombat_JSBSim空战环境\  ← 已下载：1v1/2v2 空战 RL 环境 + PPO/MAPPO
│   └── BVRGym_超视距空战RL环境\       ← 已下载：超视距空战 + 行为树对手

└── 04_参考与备查\                ← 未能下载/超大规模的备查资源
```

## 与本项目的关系

| 项目需求 | 对应资源 |
|---------|---------|
| F-104 单机机动演示数据（行为克隆/JRRL引导） | UAVDB（真实机动）、CAFUC（真实训练机动）、本组自采轨迹（《05》规范） |
| 超视距交战规则与行为树节点参考 | BVRGym 的 `jsb_gym/bts/BVR`（规避/追击/发射条件节点） |
| 1v1/2v2 空战 RL 环境架构参考 | CloseAirCombat（分层控制+导弹模型）、BVRGym（三级架构） |
| Gym 接口封装（计划书步骤 2.3） | gym-jsbsim（HeadingControlTask 等接口范例） |
| 机动识别（敌方战术动作识别） | CAFUC、aircraft_maneuver_classification、MIT AIA（备查） |

## 使用提醒

1. 各子目录内有独立说明文件，下载/使用前先读；
2. 第三方数据**仅用于学习与研究**，引用时注明来源与许可证（各说明文件已列）；
3. 本目录内容与项目自采数据（`JSBSim_培训与验证资料\样例数据\`）互补：外部数据提供动作定义与接口参考，训练主数据仍以本项目标准轨迹格式（trajectory_v1）为准；
4. 新增外部数据集时：按"单机/多机 → 动作/场景名称"归类，文件名用 `说明_<名称>.md` 与 `数据\`、`源码\` 子目录，并同步更新 `数据清单.md`。
