# aircraft-maneuver-classification（机动分类数据集，需自行克隆）

## 基本信息

| 项目 | 内容 |
|------|------|
| 仓库 | https://github.com/tranngocphu/aircraft-maneuver-classification |

| 说明 | 本次整理时仓库打包下载超时（数据文件较大），未能直接入库；组员可自行克隆 |

## 获取方式

```powershell
git clone https://github.com/tranngocphu/aircraft-maneuver-classification.git
# 克隆后把 dataset 文件夹复制到本目录的 数据\ 子目录
```

## 用途

- 机动分类的**数据组织方式**（特征列 + 标签列）参考；
- 与 CAFUC、UAVDB 配合，作为本项目"敌机战术动作识别"（计划书行为树 Orientation 环节）的数据组织范例。

> 注意：使用前查看仓库许可证；仅用于学习研究。
