# 开源项目库（深度学习参考项目）

本目录收集与本大创项目（忠诚僚机超视距空战：DRL 机动决策 + LLM/行为树知识引导 + 多机协同）**直接相关且可运行**的开源深度学习项目，作为开发参考与代码基础。

**筛选标准（2026-08-17 确认）：**
| 维度 | 标准 |
|------|------|
| 领域 | 空战机动决策 DRL、LLM 行为树生成、多智能体协同 RL |
| 语言/框架 | Python + **PyTorch** |
| 模型 I/O | 输入 1 Hz 飞行状态向量（20-30 维）+ 任务文本；输出机动动作（油门/坡度/俯仰/武器）——所选项目均可适配此接口 |
| 许可证 | 开源即可（本批全部为 MIT/Apache-2.0/BSD 类） |
| 活跃度 | 2024 年后仍有提交（jumpstart-rl 除外，为论文标准实现，仅作参考） |

## 目录结构

```
开源项目库\
├── README.md                      ← 本文件
├── 01_强化学习算法库\
│   ├── stable-baselines3\         ← PPO/SAC/TD3 主流实现（13.7k★，MIT）
│   ├── tianshou\                  ← 清华 DRL 库，中文文档（10.9k★，MIT）
│   ├── jumpstart-rl\              ← JSRL 论文实现（MIT，计划书算法直接对应）
│   └── CleanRL\                   ← 单文件 PPO 实现（10.3k★，MIT）
├── 02_多智能体强化学习\
│   └── MARLlib\                   ← 多智能体 RL 算法库 MAPPO 等（1.3k★，MIT）
└── 03_行为树与LLM\
    ├── py_trees\                  ← Python 行为树框架（BSD，活跃）
    └── BTGenBot\                  ← LLM 生成行为树（IROS 2024，MIT）
```

## 选择理由速览

| 项目 | 对应项目模块 | 一句话理由 |
|------|------------|-----------|
| stable-baselines3 | 阶段三 PPO 训练 | 最主流的 PPO 实现，jumpstart-rl 也基于它，可直接挂接自定义 Gym 环境 |
| tianshou | 阶段三训练备选/教学 | 清华出品、中文文档、支持多智能体，适合组员上手 |
| jumpstart-rl | 阶段二/三 JSRL 引导 | 计划书 JSRL 算法的标准第三方实现，含 curriculum/random 两种引导 |
| CleanRL | PPO 定制改造 | 单文件 PPO，改奖励/网络/观测最方便，适合深度定制 |
| MARLlib | 阶段四 2v2 协同 | 多智能体 PPO/MAPPO 等，2v2 效能评估的算法候选 |
| py_trees | 阶段二行为树执行 | Python 行为树事实标准，BVRGym 的行为树也基于它 |
| BTGenBot | 阶段二 LLM 行为树生成 | 轻量 LLM 微调生成行为树（含数据集与验证器），与 LLM 生成模块同构 |

## 与既有资料的关系

- `飞行数据集资料库\02_多机空战与协同\` 下的 CloseAirCombat（PPO/MAPPO 实现）与 BVRGym（py_trees 行为树）是**空战环境级**项目，本目录是**算法/框架级**项目，两者互补；
- 本目录仅存放第三方代码，项目自研代码不在此处修改。

## 使用提醒

1. 各项目子目录内有 `说明_<名称>.md`：简介、选择理由、安装与最小运行示例；
2. 引用第三方代码时保留原许可证文件（源码包内已含）；
3. 优先 `pip install` 官方包，本目录源码用于阅读、对照与二次开发参考。
